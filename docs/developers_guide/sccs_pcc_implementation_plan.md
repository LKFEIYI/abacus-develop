## 1. 目标、范围与设计决策

采用 ABACUS 原生 C++ 实现，不链接 Environ。以 Andreussi 系列论文确定物理模型，以固定版本 Environ 为主要数值参考，以指定 CP2K 版本为独立静电对照。

首版范围：

- 平衡静态介电响应，电子密度依赖的 SCCS 空腔。
- 非静电能 `gamma_eff * surface + pressure_eff * volume`，包含相应势与力。
- 孤立中性分子与净电荷为正、负的分子离子；优先验证闭壳层、整数电子体系。
- 几何上正交等边的立方计算超胞，零维 PCC；电子结构仍使用三维周期网格和 Γ 点。
- CPU、串行及 MPI；PW 作为基组收敛参考，LCAO 是首版最终验收范围。
- 固定晶胞 SCF、单点能量和力；解析力通过验证后开放固定晶胞结构优化。
- 保留旧 `imp_sol` 模型和默认行为，新增模型选择，不静默替换旧算法。

首版不包含：应力与变胞优化、二维电极、恒电势、Poisson–Boltzmann 电解液、非平衡溶剂响应、solvent-aware 非局域空腔、MT、GPU 原生求解、非共线磁性及 SOC 的完整验证。多价离子与强配位体系可以后续测试，但不作为首版精度承诺。

“支持带电分子”表示静电边界、泛函和数值计算正确；它不自动意味着所有离子的实验水合自由能均达到同一误差水平。

## 3. 符号、单位与密度契约

### 3.1 统一内部约定

建议 SCCS 数学核心采用 Hartree 原子单位，ABACUS 适配层统一转换为 Ry。不得根据数组名称猜测现有势的符号和单位。

| 量 | 定义 | 内部单位 |
| --- | --- | --- |
| `n` | 正的价电子数密度，两个共线自旋通道之和 | bohr^-3 |
| `rho_ion` | 与赝势价电荷对应的正离子模型电荷密度 | e/bohr^3 |
| `rho_sol` | `rho_ion - n`，物理溶质电荷 | e/bohr^3 |
| `q_sol` | `sum(Z_valence) - N_e` | e |
| `n_cav` | 定义空腔的非负密度 | bohr^-3 |
| `rho_pol` | 介电极化电荷，保留真实积分 | e/bohr^3 |
| `phi` | 正试探电荷感受到的静电势 | Hartree/e |
| `v_ks` | 对正电子数密度的泛函导数 | Hartree |
| `s` | 溶质指示函数，内部 1、溶剂区 0 | 无量纲 |
| `S`、`V_cav` | 空腔表面积、体积 | bohr^2、bohr^3 |
| `gamma_eff`、`p_eff` | 有效表面和体积系数 | Hartree/bohr^2、Hartree/bohr^3 |

`E_Ry=2 E_Ha`、`v_Ry=2 v_Ha`、`F_Ry/bohr=2 F_Ha/bohr`。输入的 dyn/cm、GPa 在参数解析边界转换一次，日志同时输出用户单位和内部单位。

密度 FFT 的归一化必须用 ABACUS 实际约定验证：若正变换带 `1/Omega`，则 `rho_sol(G=0)=q_sol/Omega`。周期 Poisson 可将势零频设零，但不得因此覆盖源电荷的物理零频。

### 3.2 区分三种电荷/密度

1. 定义空腔的 `n_cav`。
2. 介电方程使用的平滑 `rho_sol`。
3. 与宿主 Ewald 一致的点离子加电子密度，用于真空 PCC 多极矩。

首个受控实现以 `n_cav=n`、局域化平滑离子源为起点；若核区出现介电渗入，增加显式模型核心密度选项 `n_cav=n+n_core_model`。在冻结默认模型前，必须对参考程序使用的电子/核心密度做同定义核对。不能把加核心密度后的模型直接标为与原参数化等价。

平滑离子源建议采用归一化高斯，逐元素固定宽度；其支撑有效范围必须位于 `epsilon≈1` 的区域。测试应扫描高斯宽度，证明反应能在可接受范围内不依赖宽度。当前从局域赝势反推源的方案可作另一种对照，不与高斯模型在不同公式中混用。

所有极化量必须保存实际密度；不能用“对反应势做周期 Laplacian、删除 G=0”的方法重建孤立极化总电荷。

## 4. SCCS 空腔、介电函数与非静电项

### 4.1 Andreussi 介电函数

设 `0 < n_min < n_max`，`epsilon_b >= 1`。过渡区定义

\[
D=\ln(n_{\max}/n_{\min}),\quad
x=\frac{\ln n_{\max}-\ln n_{\mathrm{cav}}}{D},\quad
f=x-\frac{\sin(2\pi x)}{2\pi}.
\]

低密度区令 `f=1`，高密度区令 `f=0`；定义

\[
s=1-f,\qquad \epsilon=\exp[f\ln\epsilon_b].
\]

过渡区解析导数：

\[
\frac{df}{dn_{\mathrm{cav}}}
=-\frac{1-\cos(2\pi x)}{D n_{\mathrm{cav}}},\qquad
\epsilon'=\epsilon\ln\epsilon_b\,f',\qquad s'=-f'.
\]

区间外导数为零；先判断区间再取对数，避免零或微小负密度导致 NaN。对负密度区分舍入噪声与显著非物理密度，并记录诊断，不用无说明的截断掩盖输入错误。

一次调用同时输出 `s`、`ds_dn`、`epsilon`、`deps_dn`，防止各计算路径使用不一致的函数。`epsilon_b=1` 是正常测试分支，空腔仍由密度阈值定义。

### 4.2 非静电泛函

采用与上述溶质指示函数一致的定义：

\[
V_{\mathrm{cav}}=\int s\,d\mathbf r,\qquad
S=\int |\nabla s|\,d\mathbf r,\qquad
G_{\mathrm{ne}}=\gamma_{\mathrm{eff}}S+p_{\mathrm{eff}}V_{\mathrm{cav}}.
\]

数值上可使用

\[
S_\eta=\int\left(\sqrt{|\nabla s|^2+\eta^2}-\eta\right)d\mathbf r.
\]

减去 `eta` 避免平坦区域引入随超胞体积增长的伪表面能。`eta` 的单位是 bohr^-1，必须扫描收敛，不能直接借用密度下限。

对应连续形式的密度导数为

\[
v_{\mathrm{ne}}=
s'\left[p_{\mathrm{eff}}-
\gamma_{\mathrm{eff}}\nabla\cdot
\frac{\nabla s}{\sqrt{|\nabla s|^2+\eta^2}}\right].
\]

离散实现必须从实际离散能量求导：梯度与负散度互为伴随、使用同一积分权重和网格；不能一边计算 `|grad(s)|`，另一边无条件采用离散上不等价的 `|s'(n) grad(n)|`。需要说明 FFT 截断、乘积回网格和抗混叠策略。

若 `n_cav` 含随原子移动的核心密度，还必须包含 `ds/dR_a` 的显式原子力。

### 4.3 参数集与跨程序差异

以下为上述固定 Environ 版本 `input.f90` 的电子密度空腔参数，作为复现起点：

| 参数集 | n_min (bohr^-3) | n_max (bohr^-3) | gamma_eff (dyn/cm) | p_eff (GPa) | epsilon_b |
| --- | ---: | ---: | ---: | ---: | ---: |
| water-neutral | 0.0001 | 0.0050 | 47.9 | -0.36 | 78.3 |
| water-cation | 0.0002 | 0.0035 | 5.0 | 0.125 | 78.3 |
| water-anion | 0.0024 | 0.0155 | 0.0 | 0.45 | 78.3 |

中性参数在该版本说明文档中有 50 dyn/cm、-0.35 GPa 的近似值；复现以实际源码与展开后的输入为准。参数集由用户显式选择，显式数值覆盖预设的优先级必须固定并完整打印。不按迭代中的净电荷自动切换参数。

CP2K 指定版本的非静电空腔使用 `(epsilon_b-epsilon)/(epsilon_b-1)`，与此处 `s=1-f` 不同，并使用密度差分求表面积。因此与 CP2K 首先比较静电分量；只有统一空腔定义后才比较非静电能或总溶剂化能。

## 5. Poisson 方程、极化迭代与零维 PCC

### 5.1 主求解路径

物理方程为

\[
\nabla\cdot(\epsilon\nabla\phi)=-4\pi\rho_{\mathrm{sol}}.
\]

使用极化电荷表示：

\[
\rho_{\mathrm{pol}}=
\frac{1}{4\pi}\nabla\ln\epsilon\cdot\nabla\phi
-\frac{\epsilon-1}{\epsilon}\rho_{\mathrm{sol}},\qquad
\phi=K[\rho_{\mathrm{sol}}+\rho_{\mathrm{pol}}].
\]

首版孤立体系主路径采用极化电荷固定点迭代，`K` 为“周期 FFT Coulomb 核＋PCC 修正”。这便于显式保存极化电荷并将边界修正纳入每次迭代。旧 CG 可用于中性周期体系的交叉核对，不直接把周期 CG 的零频投影视为孤立求解器。

带电的纯周期诊断路径必须明确使用中和源，并按 2014 年论文式 (38) 处理背景极化；不能将孤立公式与一个自动丢弃零频的周期求解器拼接后声称模型相同。

### 5.2 PCC 势及解析电场

设立方边长 `L`，`Omega=L^3`，在共同原点下对真实源密度计算

\[
q=\int\rho,\quad
\mathbf d=\int\mathbf r\rho,\quad
Q=\int r^2\rho.
\]

定义修正方向为“孤立近似势减周期势”，取正的立方 Madelung 常数 `alpha≈2.837297479`：

\[
\Delta\phi_{\mathrm{PCC}}[\rho](\mathbf r)=
\frac{\alpha q}{L}
-\frac{2\pi}{3\Omega}
\left(qr^2-2\mathbf d\cdot\mathbf r+Q\right),
\]

\[
\nabla\Delta\phi_{\mathrm{PCC}}
=-\frac{4\pi}{3\Omega}(q\mathbf r-\mathbf d).
\]

介电迭代中的源是 `rho_sol+rho_pol`，不是只有溶质，也不再额外将结果除以 `epsilon_b`。真空参考使用 `rho_sol`。

实现要求：

- 势与梯度由同一组多极矩生成；所有积分用真实电荷和 MPI pool 归约。
- 周期势使用 FFT 求导；PCC 的非周期多项式梯度解析加入，不能对整个修正势做周期 FFT 求导。
- 不能通过周期 FFT Laplacian 检查 PCC 多项式在超胞边界的残差；应在物理有效内部区域检查，或单独使用解析项。
- 保留常数项。它不改变电场，但影响带电体系的能量和电势参考，不能每次把最终势重新强制减均值。
- 首版几何检查要求正交、等边的计算晶胞；不沿用仅看 `latname=sc/fcc/bcc` 的判断。FCC/BCC 原胞通常并非这里的立方盒。
- 固定原点建议为盒中心；要求分子与空腔局域在同一个连续表示内。跨边界分子先统一展开/居中，不能对每项多极矩分别随意最小镜像。
- 电荷或空腔触及边界时给出定量诊断并拒绝不满足精度条件的生产计算。PCC 是有限阶修正，仍需超胞收敛。

### 5.3 每个电子 SCF 步的内循环

```text
输入：电子密度、原子位置、晶胞、上一步极化状态
构建 n_cav、rho_sol、s、epsilon、导数和 grad(log epsilon)
校验真实净电荷、立方几何、空腔和电荷局域性

重复：
    rho_total = rho_sol + rho_pol
    计算 rho_total 的 q、d、Q
    phi = phi_periodic + phi_PCC
    grad_phi = grad_phi_periodic + analytic_grad_phi_PCC
    rho_pol_trial = 固定点映射(epsilon, rho_sol, grad_phi)
    residual = rho_pol_trial - rho_pol       # 混合前残差
    评估残差、能量变化、极化总电荷和非有限值
    未收敛：混合 rho_pol，继续迭代

在最终 rho_pol 上重新计算一致的势、场、能量和残差
计算真空参考、非静电量、Kohn–Sham 势及所需力数据
返回结果和显式收敛状态
```

首版先使用阻尼线性混合；困难算例再增加有测试依据的 DIIS。不能通过减小 mixing 使“混合后变化量”虚假满足收敛。

同时监控体积归一化 RMS 和最大绝对残差，并打印每项单位；单一依赖网格点数的欧氏范数不适合作为可移植容差。残差阈值、最大迭代数和混合参数可配置，首次测试确定默认值，不照搬旧 CG 的硬编码阈值。

极化迭代达到上限、出现 NaN 或发散时，返回失败并终止该计算；不能继续输出被标记为收敛的总能量或力。复用极化历史前检查晶胞、网格、模型参数是否变化，显式重置失效历史。

### 5.4 极化总电荷诊断

孤立、局域化体系满足

\[
q_{\mathrm{pol}}=-\left(1-\epsilon_b^{-1}\right)q_{\mathrm{sol}},
\qquad q_{\mathrm{total}}=q_{\mathrm{sol}}/\epsilon_b.
\]

用它诊断求解与边界精度。有限阶 PCC、网格误差和边界截断可能产生偏差，必须随超胞和网格收敛，不得靠事后强制归一化来掩盖错误。若未来引入约束归一化，需要重新说明所求方程和变分一致性。

## 6. 能量、势与原子力的一致性

### 6.1 能量记账方式

定义宿主原有周期真空能量为 `E_host_PBC[n,R]`。建议拆分为

\[
E_{\mathrm{new}}=
E_{\mathrm{host,PBC}}+
\Delta E_{\mathrm{vac,PCC}}+
G_{\mathrm{pol,PCC}}+G_{\mathrm{ne}}.
\]

其中真空部分使用与宿主 Ewald 一致的点离子多极矩：

\[
\Delta E_{\mathrm{vac,PCC}}=
\frac{\alpha q_{\mathrm{sol}}^2}{2L}
-\frac{2\pi}{3\Omega}
\left(q_{\mathrm{sol}}Q_{\mathrm{sol}}-|\mathbf d_{\mathrm{sol}}|^2\right).
\]

在一致平滑源与边界处理下，反应能目标表达式为

\[
G_{\mathrm{pol,PCC}}=
\frac12\int\rho_{\mathrm{sol}}^{\mathrm{smooth}}
\left(\phi_\epsilon^{\mathrm{PCC}}-\phi_0^{\mathrm{PCC}}\right)d\mathbf r.
\]

这是一种待落实到离散实现的分项契约，不表示平滑离子与点离子可以随意替换。里程碑 M0 必须将它与论文的总修正形式及附录逐项核对：列出两种表示的四极矩差、必要的能量/势/力补偿，说明哪些项已由该拆分计入。若采用论文混合表示而非上述拆分，则附录 A1 等相应项必须显式实现；不能两套记账混加。

不得仅把“周期溶剂反应能”加到未修正的宿主真空能量后称为孤立 SCCS；不得仅修正最终标量能量而让电子密度在另一套势下自洽。

### 6.2 Kohn–Sham 环境势

在 `rho_sol=rho_ion-n`、`n_cav=n+固定核心密度` 的约定下，反应泛函的连续目标形式为

\[
v_{\mathrm{pol}}=
-\left(\phi_\epsilon^{\mathrm{PCC}}-\phi_0^{\mathrm{PCC}}\right)
-\frac{1}{8\pi}\frac{d\epsilon}{dn}|\nabla\phi_\epsilon^{\mathrm{PCC}}|^2.
\]

另外加入真空 PCC 能量的电子密度导数和 `v_ne`。所有场都应包含所需 PCC 修正，不能在能量中用修正场、在介电导数势中用未修正场。实际离散泛函与核边界近似带来的额外项须在 M0 推导并通过方向导数测试确认，以上连续式不代替该测试。

`cal_delta_eband()` 已按动态有效势扣除密度积分。新环境势接入后只添加真实环境能量分项，不另行重复扣除 `integral(n*v_env)`；同时核对 `cal_delta_escf()`、输入/输出密度使用时机和最终收敛能量。

### 6.3 关键极限

| 设置 | 预期 |
| --- | --- |
| 关闭新增模型 | 原有结果保持在回归容差内 |
| epsilon_b=1，gamma_eff=p_eff=0，PCC 关闭 | 所有新增贡献为零 |
| epsilon_b=1，gamma_eff=p_eff=0，PCC 开启 | 极化能为零，但真空 PCC 能量、势和力保留 |
| epsilon_b=1，仅非静电系数非零 | 独立保留表面/体积贡献，不通过除以 epsilon_b-1 构造空腔 |
| 中性体系且 PCC 开启 | 单极项为零，偶极等修正不一定为零 |

### 6.4 原子力与 LCAO

原子力必须由同一已收敛泛函求导，至少覆盖：

- 反应势与平滑离子源位置导数的耦合。
- 真空 PCC 点离子贡献及与平滑表示相关的补偿。
- 模型核心密度导致的空腔显式位置导数，包括介电和非静电项。
- 宿主已有局域势、非局域赝势及基组相关力的正确组合。

LCAO 的环境矩阵元为

\[
\Delta H_{\mu\nu}=\int\phi_\mu^*v_{\mathrm{env}}\phi_\nu\,d\mathbf r.
\]

让 `v_env` 进入已有网格积分和相应基组导数力路径；新增模块仅返回该路径未包含的显式环境力。不能把新增环境势贡献计算两次，也不能认为“返回一份离子力数组”就涵盖全部 LCAO 力。

PW 与 LCAO 都进行总能量有限差分；LCAO 另检查基组大小、径向截断、密度尾部及网格收敛。先验证闭壳层 `nspin=1`，共线 `nspin=2` 需要验证势作用于两个通道而力不被重复求和。

### 9.1 单元与固定密度测试

| 测试 | 验证内容 | 建议门槛 |
| --- | --- | --- |
| 空腔标量函数 | 阈值、极限、连续性、解析导数 | 非极小值区相对误差约 1e-8；端点用绝对误差 |
| 非静电方向导数 | 离散能量差分对比势积分 | 扫描扰动步长，达到约 1e-6 相对误差平台 |
| 电荷积分/FFT | 归一化、G=0、正负净电荷 | 合成光滑输入的积分误差 <1e-8 e |
| 周期 Poisson | 常介电正弦源解析解 | 势/场相对误差 <1e-8（可表示的 Fourier 模式） |
| PCC 多项式 | 正负 q、d、Q、常数与解析梯度 | 代数测试绝对误差约 1e-12 a.u. |
| PCC 核对称性 | `<a,Kb>=<Ka,b>` | 同离散表示内相对差约 1e-10 |
| 静电泛函方向导数 | 总新增能量对电子密度导数 | 随步长、内迭代和网格收敛达到约 1e-5 相对误差 |
| 模型电荷力 | 固定电子密度、移动平滑离子与核心 | 与同一离散能量有限差分一致 |
| 失败路径 | 内迭代上限、非法几何、NaN、冲突输入 | 显式失败，不能给出成功标记 |

方向导数使用

\[
\frac{E[n+h\delta n]-E[n-h\delta n]}{2h}
\quad\text{对比}\quad
\int v[n]\delta n\,d\mathbf r.
\]

对保持电子数的扰动先验证形状响应；再在固定空腔或受控模型中验证改变净电荷的扰动，以识别遗漏的 PCC 常数项。零附近以绝对误差判定，不能使用不稳定的相对误差。

### 9.2 连续介质解析模型

- 固定球形空腔内的中心电荷，以远离界面的局域平滑源测试 Born 极限 `G=-(1-1/epsilon_b)q^2/(2a)`。
- 光滑界面不能直接要求等于尖锐界面的 Born 公式；使用径向数值参考，或明确进行界面变窄的收敛外推。
- 正负等量电荷在相同固定空腔中的线性介质能量应相同、势和极化电荷反号；自洽密度空腔和不同参数集不要求这种对称性。
- 扫描介电常数、盒尺寸、网格和离子高斯宽度，分离内迭代误差与边界/离散误差。
- 孤立极化总电荷偏差目标 <1e-4 e，并展示随网格和盒尺寸的趋势；高介电常数下同时报告屏蔽后总电荷的相对误差。

### 9.3 分子测试集

| 类别 | 首批体系 | 主要目的 |
| --- | --- | --- |
| 中性非极性 | CH4 | 空腔和非静电项、旧模型回归隔离 |
| 中性极性 | H2O、CH3OH | 偶极 PCC、自洽响应、力 |
| 阳离子 | NH4+、后续质子化吡啶 | 净正电荷、参数集、尺寸收敛 |
| 阴离子 | CH3COO-、后续 Cl- | 净负电荷、弥散密度、赝势与基组敏感性 |
| 开放壳层扩展 | 固定多重度的分子自由基离子 | nspin=2、占据与自旋一致性 |

每个测试记录结构、净电荷、多重度、泛函、赝势校验和、轨道文件、网格、截断能、占据、SCF 阈值和完整模型参数。不要把质子化吡啶自动等同于论文中的“pyridine cation”；复现论文时以原始结构与电子数为准。

### 9.4 跨程序对照

按以下层次进行，不能仅比较不同程序的总绝对能量：

1. 同一标量密度输入：epsilon、s、导数、S、V；非静电定义相同时才要求相等。
2. 同一固定溶质电荷和空腔：势、场、极化密度、反应能。
3. 完整 SCF：比较各程序自己的 `E_solvated-E_vacuum`，匹配边界和参数；记录基组、赝势与密度差异。
4. 力：优先要求各程序自身的能量—力一致性，再在设置充分匹配时做跨程序比较。

Environ PCC 为主对照；CP2K MT/analytic 为充分收敛孤立静电参考。有限盒下 PCC 和 MT 不要求逐点完全一致，应比较内部物理区域和大盒极限。

参考势比较必须记录电势零点约定：周期势可对齐共同常数后比较形状；PCC 的带电能量和常数项单独验证，不能用任意常数对齐掩盖错误。

建议固定密度反应能误差目标为 1e-5–1e-4 Ha（设置和网格足够一致时），完整分子溶剂化能跨程序差异目标先取 0.01–0.03 eV 并分析来源，不将基组/赝势差异归入实现容差。

### 9.5 力、尺寸、平移及并行

- 解析力与中心差分比较，位移试取 0.002、0.005、0.01 bohr，寻找截断误差和 SCF 噪声之间的平台。
- 首批分子最大分量误差目标 <1e-4 Ha/bohr，进一步目标 <1e-5 Ha/bohr；先收紧电子和极化内循环再判断。
- 同时测试总力和溶剂/PCC 力分项；力验证使用同一完整能量表达式。
- 示例盒边长 20、25、30、35 bohr，仅用于足够小且已满足边界局域性的分子；更大分子按空腔实际尺寸增加。
- 比较真空能、溶液能、反应能与溶剂化能，不只依赖差值的偶然抵消。最后两个收敛盒的溶剂化能变化目标 <0.01 eV。
- 分子整体平移整数网格及分数网格位置，保持不触碰边界，检查能量、势和力的网格误差；网格加密后应收敛。
- 固定参数分别以 1、2、4 MPI 进程运行。能量差目标 <1e-8 Ha、力差 <1e-7 Ha/bohr；迭代数可以略有不同。
- LCAO 逐步扩大轨道基组和径向范围，重点检查阴离子尾部、边界密度与电子局域性；增加真空层不能替代基组收敛。

### 9.6 实验溶剂化自由能

实现验收先针对能量泛函和数值一致性。与实验对比时另列：气/液相结构、热修正、标准态、单离子电势参考、参数集和电荷态稳定性。不能把 `G_pol` 单独当作完整实验自由能。对气相不束缚或电子泄漏的阴离子，需先明确物理参考态，不用有限盒结果强行构造“溶剂化能”。

PCC 不等 M6 才考虑力：M0 即推导，M3/M4 在模型电荷上验证导数，M6 完成电子结构与 LCAO 的完整集成。

每个阶段保持可单独编译和测试；符合项目提交工作流时按阶段提交。若当前目录不具备有效可写 Git 元数据，应如实记录这一限制，不能伪称完成提交。

失败时优先定位：

- 固定密度能量—势不一致：先修泛函/离散/单位，不调 SCF 混合掩盖。
- 盒尺寸收敛失败：先查背景、PCC 多极矩、源电荷支撑和常数项。
- 力失败但势通过：查离子表示、空腔显式导数、PCC 原点和 LCAO 基组导数分工。
- 仅 MPI 失败：查 pool、复制数据归约、G=0 所属进程与网格全局索引。
- 仅阴离子失败：同时检查实现残差、轨道弥散性与物理束缚性，不直接更换拟合参数。

## 11. 输出、回归数据与项目规范

每次计算建议输出：

- 真实 `N_e`、`q_sol`、`q_pol`、屏蔽后总电荷及预期偏差。
- epsilon 最小/最大值、空腔体积/表面积、边界密度/空腔指标。
- 内循环次数、混合前 RMS/最大残差、是否收敛及最终能量变化。
- `E_pol`、`E_surface`、`E_volume`、`E_pcc_vac` 和必要补偿项，注明单位。
- PCC 原点、几何判定、源电荷模型、全部展开参数及程序版本。
- 可选网格场：`n_cav`、epsilon、`rho_pol`、反应势、PCC 势、总环境 KS 势；场元数据标明符号、单位和电势参考。

测试源码按 `test_<module_name>.cpp` 命名，加入实际 `CMakeLists.txt`。沿用 CMake/CTest，不新增独立工具链。运行测试使用 `OMP_NUM_THREADS=1`，MPI 的环境问题按仓库规范在适当执行环境复核。

已有 `MODULE_HAMILT_surchem_*` 测试保留；新测试目标名在实现时注册，不把计划名称当成现存命令。INPUT 完成后验证帮助和 `--check-input`，从 C++ 注册生成参数文档，不手工编辑生成文件。

参考数据保存输入、网格规格、参考版本、产生步骤和数值容差，不仅保存一列最终能量。每个里程碑报告实际执行的构建、测试和失败项；本设计文档本身不构成任何数值验证。
